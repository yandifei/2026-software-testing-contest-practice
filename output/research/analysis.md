# Research 本轮测试范围与剩余缺口

本轮从官方题包核对全部生产源码及 POM，复用历史单文件场景，移除 6 个访问私有字段/构造器的反射测试，补入 3 个公开接口测试：连续 ID 正值/唯一性与往返解析、预算储备比例重设、固定零抽样的零概率风险。

保留预算子集穷举参照、固定随机序列、图依赖与循环、预约状态、人员分配、任务状态、报告内容、边界与异常断言。预期值不由被测方法计算。

## 已知缺口

- ID 生成器负值归一化分支依赖私有静态计数器及真实时钟；本轮不改写内部状态，仅验证公开结果。因此保留未覆盖分支和相关未杀死变异，不声明等价。
- Researcher.assignTask 的 assignedCount 没有公开读取接口、也不影响后续公开行为；计数加减变异通过公开 API 无法区分。
- Budget.setReserveRatio 的负值/负零状态在常规有限、非负预算下被最低 1000 储备金遮蔽；本轮不直接读取私有字段，不将未检出表述为完全等价。
- 其余端点赋回同值、重复裁剪、集合不含 null、分位数上界等项可参照 historical-survivor-analysis.md；该文件仅提供历史语义说明，计数与当前结果不同。当前逐项状态以 survivors.json 和 ZIP 内本轮 PIT 报告为准。

当前实现的业务风险：图依赖遍历顺序反向及关键路径截断；预约忽略后续区间；任务分配缺少技能校验；预算舍入可能使实际成本超限。相关测试命名 characterizes，属于现状刻画，不宣称实现符合业务需求。
