# 2026 全国大学生软件测试大赛 · 备赛练习

本仓库用于整理 2026 年全国大学生软件测试大赛的备赛代码、单元测试和验证记录，目前围绕**开发者测试赛项**开展 Java 测试练习，包含 FastJson 与 Mathematical-Expression 两个独立 Maven 项目。

这里是个人练习仓库，赛事安排与提交要求以组委会及比赛平台最新通知为准。本地覆盖率、变异测试结果不等同于赛事平台成绩。

## 比赛概览

2026 年为第十一届全国大学生软件测试大赛，由大赛组委会及中国计算机学会软件工程、系统软件、容错计算专业委员会等共同组织，面向全国全日制高校在校研究生、本科、专科及高职高专学生。大赛不收取报名费；线下总决赛的差旅食宿由参赛者自理或所在学校承担。

| 赛项 | 主要内容与工具 | 赛制 |
| --- | --- | --- |
| 拓思杯开发者测试大赛 | 在慕测平台提交基于 JUnit 编写的测试脚本，可自行选择 IDE | 预选赛 → 省赛／同期网络赛 → 总决赛 |
| 慕测杯 Web 应用测试大赛 | 功能测试用例、Selenium、Java／Python 及测试框架 | 预选赛 → 省赛／同期网络赛 → 总决赛 |
| 凯云杯嵌入式测试大赛 | ETest5 Web 端、Python 测试脚本及测试报告 | 预选赛 → 省赛／同期网络赛 → 总决赛 |
| 微信小微 AI 助手评测专项赛 | 真实场景体验、问题发现、满意度分级与材料提交 | 初赛 → 总决赛，不设省赛 |

前三项设个人赛和高职团队赛；高职团队赛每队为同校最多 3 名学生、最多 2 名指导教师。小微专项赛仅设个人赛。上述内容依据通知正文第 1–8 页，并与[官方报名公告](https://www.mooctest.org/news_detail?new_id=184)交叉核对。

## 本地运行

本仓库两个 `pom.xml` 配置的环境为 **JDK 21、Maven 3.9.6 或更新版本、JUnit Jupiter 5.10.2**。这属于当前练习项目配置，不代表比赛统一环境要求；正式提交前需要按赛题确认 JDK、JUnit、依赖与可提交文件范围。

首先检查环境：

```shell
java -version
mvn -version
```

克隆仓库后，分别进入项目执行，首次运行需要联网下载 Maven 依赖：

```shell
git clone https://github.com/yandifei/2026-software-testing-contest-practice.git
cd 2026-software-testing-contest-practice

cd FastJson_1779071911271
mvn clean test
cd ..

cd Mathematical-Expression_1776829302591
mvn clean test
cd ..
```

两个项目均配置 JaCoCo 和 PIT。在任一项目目录执行变异测试：

```shell
mvn test org.pitest:pitest-maven:mutationCoverage
```

FastJson 另提供完整验证脚本，需要 PowerShell 7 和可从 `PATH` 调用的 Maven。在仓库根目录运行：

```powershell
pwsh -File ./FastJson_1779071911271/scripts/verify.ps1
```

脚本依次执行干净构建与测试、Checkstyle、PIT，并生成验证汇总。FastJson 的部分 Java 反序列化测试依赖 POM 中的 `--add-opens java.base/java.io=ALL-UNNAMED` 配置；平台若限制 JVM 参数，需要重新适配和验证。

## 备赛练习方法

1. 阅读被测 API 和实现，列出输入类别、返回值、异常与可观察副作用。
2. 为正常路径、空值、边界值和异常输入写明确断言，避免只验证“不抛异常”。
3. 运行单元测试与 JaCoCo，按遗漏分支补齐用例。
4. 运行 PIT，逐项分析存活变异，区分断言不足、等价变异和环境限制。
5. 保持测试可重复，恢复测试改动过的全局状态；记录缺陷及复现条件。
6. 正式提交前按比赛平台的依赖、命名、文件范围与评分要求重新验证。

以上为本仓库练习建议。JUnit 是通知明确提到的工具；JaCoCo、PIT、Mockito 及本地检查脚本是仓库使用的辅助工具，不据此推断官方评分公式或允许的全部依赖。
