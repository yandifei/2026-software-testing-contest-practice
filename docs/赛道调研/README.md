## 个人赛与高职团队赛

- 参赛范围：全国全日制高校在校研究生、本科、专科及高职高专学生。
- 前三个赛项各有个人赛和高职团队赛。个人赛配置为 1 名选手、1 名指导教师；高职团队赛仅限高职高专学生，同校最多 3 名学生、最多 2 名指导教师。
- 高职团队由队长账号报名，不可重复组队。小微专项赛仅个人参赛，不接受企业或团队报名。
- 通知第 3 页要求填写指导教师信息，第 9 页又注明自行参赛可不填；请按报名表和组委会答复处理，不把“无指导教师”直接推定为不能参赛。
- 指导教师、队员等信息在省赛登记确认后不能再随意调整；小微的信息修改截止另有规定。

依据：通知第 3、4、9 页。高职团队训练可按“需求与用例 / 脚本执行 / 证据与提交”分工，但比赛时允许的协作方式仍须遵守赛项要求。

## 必须再确认的事项

1. **运行环境与提交格式**：已核对开发者与 Web 课件中的主要版本、交付和模板要求；精确依赖及当场上传限制按题包确认。
2. **评分细则**：开发者 2026 培训已给出评分维度与比例；其他赛项未核实的权重不采用往年比例或博客经验填补。本地 PIT 分数不等于平台总成绩。
3. **AI 辅助与联网规定**：本次已读取的总通知未明确允许比赛中使用生成式 AI；小微是 AI 产品评测也不自动意味着可以用 AI 代做材料。正式比赛前查阅赛项考生须知或获得组委会确认。
4. **线下安排**：所在省承办点、签到、设备、证件等以当地通知为准，不把某校校赛规则推广到全国。
