## 建议训练流程

工具与 AI 许可另见[核验表](工具与AI使用规则.md)。[10-16 官网第二轮通知](https://www.mooctest.org/news_detail?new_id=185)直接推荐 ETest5 培训合集，官方账号第 34 集为[AI 生成驱动适配代码](https://www.bilibili.com/video/BV1VQp16yENM/)。已确认课程涉及内置 AI 能力，但还不能推定外部 AI、模型品牌、个人 API Key 或自动代理均可用于正式比赛。

第二轮通知同时链接 Windows／Linux 部署教程，而凯云 10-10 文章说浏览器操作无需本地安装。两者分别涉及产品部署学习与赛事实例使用；是否要求参赛者自己部署，需以当场环境说明确认，不能仅凭教学视频决定。

1. **先打通入口**：从官方平台、培训或交流渠道取得赛事练习地址与账号，完成一次登录和示例运行。
2. **读需求而非只看脚本**：把功能条件、接口输入输出、时序、边界和异常处理拆成可检查项。
3. **建立测试映射**：每条需求关联测试用例、激励数据、预期输出和实际证据；是否涉及具体通信协议以题目为准。
4. **编写 Python 测试**：使用平台提供的接口或示例，在正常、边界和异常输入下记录结果，避免用想象的 API 替代真实接口。
5. **复现问题**：保存需求依据、前置状态、操作步骤、输入、期望与实际结果；确认重复执行仍能复现。
6. **完成报告与导出**：用当届模板整理问题，检查附件能被打开，按要求上传并查看最终提交状态。

建议自用记录表：`需求编号 / 输入或激励 / 时序条件 / 预期输出 / 实际输出 / 证据 / 结论`。报告是否必须包含某些字段、是否另交工程和脚本，应以当届专项说明确定。
