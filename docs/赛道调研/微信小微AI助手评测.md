## 指定 AI 与外部 AI 的区别

[10-19 官网新介绍](https://www.mooctest.org/news_detail?new_id=186)明确测试对象是微信内的**小微 AI 助手比赛指定版本**，报名成功后提供内测体验权限，不设题库或固定场景，可设计复合任务、改变表述或入口观察表现，初赛不要求所有人都有编程经验。

这里允许体验的小微是**被测产品**。公告没有据此授权使用 ChatGPT、DeepSeek、Codex、Claude、Cursor 等外部 AI 生成参赛材料，也没有给出这类工具的禁止名单。外部 AI 的辅助范围、自动化调用和披露义务仍未确认，详见[工具与 AI 使用规则](工具与AI使用规则.md)。

CNB 是作品平台，并不意味着“推送到任意 CNB 仓库就算参赛成功”。应从指南核对赛事组织、仓库权限、提交入口及回执。本仓库的 GitHub 上传也不能替代官方参赛提交。

## 备赛建议：建立可复核的场景证据

以下是自用训练方法，不是官方评分表、满意度等级或提交格式。

| 记录字段 | 建议内容 |
| --- | --- |
| 场景与目标 | 用户实际要完成什么，完成条件是什么 |
| 前置条件 | 账号状态、已授予权限、已有上下文、设备与客户端版本 |
| 输入与步骤 | 原始请求、必要上下文、后续澄清或操作 |
| 预期行为 | 可核实的正确结果或合理反馈；不凭印象认定错误 |
| 实际行为 | 完整响应、操作结果、时间和截图／录屏等可用证据 |
| 复现情况 | 相同条件下是否再次出现，哪些因素改变了结果 |
| 影响说明 | 对任务完成造成何种阻碍，是否存在绕行方法 |
| 满意度 | 先写事实依据，待官方尺度明确后再映射其等级 |

可从任务完成、事实准确、上下文理解、失败恢复和交互清晰度等角度练习。选取真实且可以验证结果的场景，记录完整证据；不要把同一问题换一种措辞重复计数，也不要将个人偏好直接当作产品缺陷。

体验权限开放前，可熟悉 CNB 基本操作并准备自己的记录表；取得官方模板后再调整。对话证据涉及个人资料时，按官方要求处理与提交，不把真实账号信息放进公开练习仓库。

## 待指南确认的关键问题

| 类别 | 需要确认 |
| --- | --- |
| 权限 | 体验资格发放时间、客户端与设备要求、账号绑定失败处理 |
| 任务 | 最少／最多场景数、有效问题定义、重复问题规则、满意度分档 |
| CNB | 赛事组织、仓库公开／私有要求、目录、模板、命名、文件格式与大小 |
| 提交动作 | 是链接、指定分支／标签、提交记录还是平台触发；如何确认收件、是否可重交 |
| 评分 | 分项权重、质量复核、同分处理与无效材料规则 |
| AI 与自动化 | 能否辅助设计场景、生成材料、自动调用产品，是否要求披露使用方式 |
| 决赛 | 现场设备、材料、体验／答辩／作答流程及具体时间 |

本次研究没有取得这些细则，不用其他 AI 竞赛规则填补，也不将备赛建议包装成官方允许的操作。

## 奖项与预期

通知第 6–7 页列出特等奖 1 名、一等奖 4 名、二等奖 10 名、三等奖 20 名，共 35 个选手奖项；对应每人奖金 10000、5000、2000、1000 元，选手奖金合计 70000 元税前，须通过资格复核。优秀指导教师奖另设 10 名、每人 2000 元。

**前 150 名晋级不等于前 150 名都有奖。** 小微不能套用传统赛项“其余决赛选手三等奖”的条款，也没有省赛证书。
