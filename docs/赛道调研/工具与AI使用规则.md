## 三、已明确的操作约束

- **开发者**：官方培训要求测试放在测试目录并集中于一个 `xxxTest.java`；不得改被测源码或 `pom.xml`。交付包括测试脚本及完整项目压缩包，包内保留测试产生的 `target` 记录；测试和变异执行须成功。细节定位见[开发者专题](开发者测试.md)。这与 Git 仓库忽略 `target/` 是两个场景，不能拿 Git 归档规则代替赛题交付要求。
- **Web**：官方培训要求保留模板代码区标识，提交前恢复规定的驱动路径；用例、脚本、截图需对应。它没有授权用 Playwright、Cypress 或其他工具替换指定 Selenium 流程，替换许可须另行确认。见[Web 专题](Web应用测试.md)。
- **全赛项**：原通知第 8 页有实名与作弊审查要求，但没有逐品牌的 AI 名单。不能把使用工具自动等同作弊，也不能用“没有点名禁止”证明任意用法合规。

正式赛各阶段、各省现场条件可能不同。练习中运行过某工具，只能证明练习可用，不能代替预选赛、省赛或决赛授权。
