## Research 交付要求

适用于上文核验的 Research-Project-Management-System 报名练习题。交付采用 **一个 Java 测试文件 + 一个完整项目 ZIP**，不是为每个被测类各交一个测试文件。

依据分开记录：

- 题包 `src/test/java/net/mooctest/BudgetTest.java` 的说明写明：“所有测试方法放在该顶层类中”，并要求文件名为 `xxxTest.java`，不建议创建内部类；2026-10-28 已直接读取此说明。
- 上述官方培训核验摘要要求全部测试集中于一个 `xxxTest.java`；这是保留的历史培训核验记录，不冒充本次重新播放验证。
- 当前页面提供一个 Java 槽和一个 ZIP 槽，并要求完整测试代码及完整项目源码与相关文件。页面本身没有单独写明“项目内只能有一个测试文件”，不能仅凭槽位数量推导单文件规则。

执行方式：保留或替换题包示例测试，将预算、任务、人员、调度等全部模块的测试集中在一个顶层测试类。可使用 `BudgetTest.java`，也可用 `ResearchProjectTest.java` 等合规名称，类名与文件名一致。不保留另一份重复或依赖的测试文件。

**禁止修改 `src/main/java/net/mooctest/` 内任何被测源代码；禁止修改 POM。** 不删除、替换、新增被测实现，也不合并生产类或变更包名。提交前比较原题包的源码清单和哈希。

完成测试和报告验证后压缩完整题目项目。推荐 ZIP 条目结构：

```text
Research-Project-Management-System_1776829451461/
├── pom.xml
├── src/main/java/net/mooctest/       原样保留
├── src/test/java/net/mooctest/
│   └── ResearchProjectTest.java      全部测试
└── target/                          执行后的产物及报告
```

这是打包示例，页面没有明确要求 ZIP 必须包含该名称的顶层文件夹。保持完整项目结构，保留题包其他必要文件，排除无关缓存和旧压缩包；输出 ZIP 放在被压缩目录之外。Java ≤2.0 MB，ZIP ≤20.0 MB，独立 Java 与包内文件字节一致。不要将整个多赛题仓库打包。
