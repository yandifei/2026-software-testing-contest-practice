# 登录、选赛与下载题目

从网页获取赛题时先执行本流程，再进入本地测试开发。此流程适用于支持浏览器控制的 Codex（ChatGPT）、Claude、WorkBuddy 等环境；不预设各产品拥有相同按钮或 API，先读取当前环境可用工具的说明。

## 1. 打开浏览器并由用户登录

1. 在 AI 编程工具的界面中打开并显示浏览器，让用户可以直接操作。优先复用用户指定的浏览器；已有慕测标签页时先读取状态，避免丢失未提交内容。
2. 未登录时访问 [慕测登录页](https://www.mooctest.net/login)。请用户在网页自行输入账号、密码并完成登录；不要在聊天中索要密码，不记录、复制或保存凭证。验证码、短信验证等由用户按当前工具规则完成。
3. 等待用户完成，读取页面确认已登录。不能把打开登录页、输入凭证或用户说“好了”单独当作登录成功；以实际页面状态为准。不要在用户输入过程中自动导航或刷新。登录后落在公告页也可正常继续，确认身份状态后直接访问比赛列表，无需重登。
4. 已登录时直接进入比赛列表，不要求退出后重新登录。环境没有可交互浏览器时，提供登录与比赛列表链接，让用户在自己的浏览器完成必要步骤；明确说明自动浏览器操作尚未执行。

## 2. 比赛列表中进入目标比赛

1. 登录后访问 [学生比赛列表](https://www.mooctest.net/student/contest)。如果跳回登录页，先解决登录状态。
2. 按用户流程向下滚动到列表底部，读取最新页面状态，查找目标赛事卡片的“进入比赛”入口。页面有分页或“加载更多”时，通过可见控件继续查找；到底部不等于已经显示全部比赛。
3. 以用户指定的年份、赛项、个人/团队、练习/正式阶段匹配。不要仅因卡片位于最后就默认是正确比赛。只有一个明确匹配时直接进入；多个无法区分时，展示标题让用户选择。
4. 点击对应“进入比赛”，核对详情页标题、阶段、时间、题目列表和提交要求。不把“报名”或其他可能改变参赛状态的按钮当成进入比赛操作；额外报名仅在用户要求时处理。
5. 已有正确比赛详情页时直接复用，从这里读取规则和下载附件，不为满足流程形式而反复返回列表。

## 3. 下载并落地题包

1. 读取目标题目名称、工程名、附件文件名及说明。用户指定单题时仅下载该题；未指定且多题无法唯一匹配时先明确范围，不默认下载全部题目。
2. 使用当前浏览器工具支持的下载方式，点击该题附件的下载按钮，等待下载完成。记录实际文件位置、文件名、来源页面和下载时间，不把点击按钮称为下载完成。
3. 将完成下载的原始 ZIP 保存到当前工作区的独立位置，例如 `contest-inputs/<题目>/`。若浏览器只能下载到默认目录，取得工具返回的真实位置后复制到工作区，不假设下载目录。
4. 保留原始 ZIP 和 SHA-256。先检查 ZIP 条目，拒绝越界路径；根据条目判断是否有顶层工程目录，不能默认解压后会自动生成同名文件夹。解压到工作区独立题目目录，不覆盖已有项目。重名时使用新目录，保留用户原有测试。
5. 核对解压后的 POM、生产源码、包名和示例测试与页面工程对应；读取题包规定。继续执行 SKILL.md 的规则记录、基线及测试阶段。

下载失败时读取页面错误、登录状态和浏览器下载结果；修正已知原因后可重试一次，仍失败则记录阻碍。保留可继续使用的页面和已下载材料，不伪造题包内容。
